# agentctl

Local-first control center for AI coding agents: unify MCP servers, skills, plugins and memory files, resolve precedence, snapshot to git.

## Getting Started

This project uses `poethepoet` for task management.

- Run the application:
  ```bash
  poe dev
  ```
- Run tests:
  ```bash
  poe test
  ```
- Format code:
  ```bash
  poe format
  ```
